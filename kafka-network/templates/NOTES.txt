Kafka chart should have:
  kafka.externalBrokerServices.enabled=true
  kafka.externalBrokerServices.create=false

For dynamic addresses, keep kafka.externalBrokerServices.autoDiscovery.enabled=true.
For fully static addresses, set the same stable IPs/DNS names as advertisedHosts in the Kafka chart.
